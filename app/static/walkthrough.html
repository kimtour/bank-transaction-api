05

FastAPI

FastAPI defines HTTP endpoints and converts Python return values into API responses.

from fastapi import FastAPI  # Imports the FastAPI class.
app = FastAPI()              # Creates the main web application object.

@app.get("/health")          # Maps HTTP GET /health to the function below.
def health():                # Defines the request handler.
    return {"status": "ok"}  # Returns a JSON response.
GET /health → FastAPI → JSON response
06

Uvicorn

FastAPI defines the application. Uvicorn runs it as a web server.

uvicorn app.main:app --reload  # Loads app/main.py, finds the app object and reloads after source changes.
  • uvicorn starts the server.
  • app.main means the main.py module inside the app package.
  • :app points to the FastAPI variable named app.
  • --reload restarts the development server when code changes.
07

SQLAlchemy

SQLAlchemy is the Object Relational Mapper used to map Python classes and operations to relational database tables and queries.

account = Account()  # Creates a Python object representing an account row.
db.add(account)       # Adds the new object to the current database session.
db.commit()           # Saves the pending change permanently.
class Account(Base):                              # Defines a SQLAlchemy model class.
    __tablename__ = "accounts"                    # Maps the class to the accounts table.
    id = Column(Integer, primary_key=True)        # Creates the integer primary-key column.
    account_number = Column(String, unique=True)  # Stores a unique account number.
    balance = Column(Numeric(15, 2), default=0)   # Stores money with two decimal places.
08

SQLite

SQLite is a lightweight relational database stored in a file. It works well for learning, prototypes, portfolio applications and local development.

DATABASE_URL = "sqlite:///bank.db"                            # Points SQLAlchemy to the local bank.db file.
engine = create_engine(                                       # Creates the SQLAlchemy database engine.
    DATABASE_URL,                                             # Uses the SQLite connection URL above.
    connect_args={"check_same_thread": False}                 # Allows FastAPI request threads to use this SQLite database.
)
FastAPI → SQLAlchemy → SQLite → bank.db

A production banking workload would typically replace SQLite with PostgreSQL or another managed database.

09

Pydantic

Pydantic validates incoming API data before the request reaches banking business rules.

from decimal import Decimal             # Imports decimal arithmetic for monetary values.
from pydantic import BaseModel, Field    # Imports Pydantic model and validation helpers.

class TransferRequest(BaseModel):        # Defines the required transfer request structure.
    source_account: str                  # Requires a source account number.
    destination_account: str             # Requires a destination account number.
    amount: Decimal = Field(gt=0)        # Rejects zero or negative transfer values.
    reference: str                       # Requires a transaction reference.

PyJWT

PyJWT creates and validates JSON Web Tokens used to protect account and transaction endpoints.

import jwt                                                    # Imports the PyJWT package.
token = jwt.encode(                                           # Creates a signed JWT.
    {"sub": "123"},                                          # Stores user ID 123 as the token subject.
    "secret-key",                                             # Uses a secret key to sign the token.
    algorithm="HS256"                                        # Uses the HS256 signing algorithm.
)
Authorization: Bearer eyJhbGciOi...  # Sends the token with an authenticated HTTP request.

Pytest

Pytest automatically checks the application after code changes.

from fastapi.testclient import TestClient  # Imports FastAPI's test client.
from app.main import app                    # Imports the FastAPI application.
client = TestClient(app)                    # Creates an HTTP client connected to the app.

def test_health():                          # Defines a test Pytest discovers automatically.
    response = client.get("/health")         # Sends a simulated request to /health.
    assert response.status_code == 200       # Requires HTTP 200.
    assert response.json()["status"] == "ok" # Requires the expected JSON status.
pytest     # Runs all discovered tests.
pytest -q  # Runs the tests with compact output.

HTTPX

HTTPX lets Python send HTTP requests and underpins common FastAPI testing workflows.

import httpx                                      # Imports the HTTPX client library.
response = httpx.get("https://example.com/api")   # Sends an HTTP GET request.
print(response.status_code)                       # Displays the returned HTTP status code.
print(response.json())                            # Parses and displays the JSON response.

.github/workflows/tests.yml

GitHub Actions runs Continuous Integration automatically when repository events trigger the workflow.

name: CI                              # Gives the workflow a visible name.
on:                                   # Defines events that start the workflow.
  push:                               # Runs after code is pushed.
    branches: [main]                  # Limits push runs to the main branch.
  pull_request:                       # Runs for pull requests.
    branches: [main]                  # Limits checks to pull requests targeting main.

jobs:                                 # Starts the automated jobs section.
  test:                               # Defines a job named test.
    runs-on: ubuntu-latest            # Uses a temporary Ubuntu runner.
    steps:                            # Starts the ordered job steps.
      - uses: actions/checkout@v4     # Downloads the repository onto the runner.
      - uses: actions/setup-python@v5 # Installs Python on the runner.
        with:                         # Supplies configuration to setup-python.
          python-version: "3.12"      # Selects Python 3.12.
      - run: pip install -r requirements.txt  # Installs project dependencies.
      - run: pytest -q                # Executes the automated test suite.
git push → checkout → Python → dependencies → tests → result

Dockerfile

A Dockerfile describes how to package the application and its runtime into a portable container image.

FROM python:3.12-slim                                                # Starts with a lightweight Python 3.12 image.
WORKDIR /app                                                         # Sets /app as the working directory inside the container.
COPY requirements.txt .                                             # Copies the dependency list into the image.
RUN pip install --no-cache-dir -r requirements.txt                   # Installs all Python dependencies.
COPY . .                                                             # Copies the application source code into the image.
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]  # Starts the FastAPI service.
18

render.yaml

render.yaml stores the deployment configuration with the source code. This approach is Infrastructure as Code.

services:                                                     # Starts the list of Render services.
  - type: web                                                 # Defines a publicly reachable web service.
    name: samuel-kimani-bank-api-demo                         # Defines the Render service name.
    runtime: python                                           # Selects the Python runtime.
    plan: free                                                # Selects the configured service plan.
    region: frankfurt                                         # Selects the hosting region.
    buildCommand: python -m pip install --upgrade pip && python -m pip install -r requirements.txt  # Installs dependencies during build.
    startCommand: python -m uvicorn app.main:app --host 0.0.0.0 --port $PORT  # Starts FastAPI on Render's assigned port.
    healthCheckPath: /health                                  # Uses /health to confirm the service is available.
    envVars:                                                  # Starts the environment-variable section.
      - key: PYTHON_VERSION                                   # Defines the desired Python version.
        value: "3.12.14"                                      # Pins the deployment to Python 3.12.14.
      - key: JWT_SECRET                                       # Defines the JWT signing secret.
        generateValue: true                                   # Lets Render securely generate the secret.
      - key: DATABASE_URL                                     # Defines the database connection string.
        value: sqlite:///bank.db                              # Uses SQLite for disposable portfolio data.
      - key: ACCESS_TOKEN_MINUTES                             # Defines JWT lifetime.
        value: "60"                                           # Sets access tokens to expire after 60 minutes.
GitHub → render.yaml → Render build → Uvicorn → /health → public application
