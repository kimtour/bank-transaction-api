01

git clone

git clone is a Git command that copies an existing GitHub repository onto your computer.

GitHub repository → your laptop
git clone https://github.com/kimtour/bank-transaction-api.git  # Copies the GitHub repository onto your computer.
cd bank-transaction-api                                        # Moves your Terminal into the downloaded project folder.

After cloning, you can edit the files locally using VS Code.

Related Git commands

git status                              # Shows which files have been changed, added, or deleted.
git add .                               # Stages all changed files so Git knows you want to include them in a commit.
git commit -m "Add banking API"         # Saves a snapshot of the staged changes with a descriptive message.
git push origin main                    # Uploads your local commits to the main branch on GitHub.
git pull origin main                    # Downloads newer changes from GitHub into your local project.

03

venv

venv means virtual environment. It creates an isolated Python environment specifically for one project so packages do not conflict with other projects.

Project A → FastAPI version A    |    Project B → FastAPI version B
python3 -m venv .venv       # Uses Python's built-in venv module to create an isolated environment named .venv.
source .venv/bin/activate   # Activates the project's virtual Python environment on macOS/Linux.
deactivate                  # Leaves the virtual environment and returns to the normal system Python environment.

When active, your terminal usually begins with (.venv).

05

FastAPI

FastAPI is a Python web framework for creating APIs. It allows Python to receive requests such as GET /accounts, POST /transactions and POST /transfers.

from fastapi import FastAPI  # Imports the FastAPI class from the FastAPI package.
app = FastAPI()              # Creates the main FastAPI application object.

@app.get("/health")          # Tells FastAPI that GET requests to /health should run the function below.
def health():                # Defines the Python function that handles the /health request.
    return {"status": "ok"}  # Returns JSON data to whoever called the API.
GET /health → {"status": "ok"}
06

Uvicorn

FastAPI defines your application. Uvicorn actually runs it as a web server.

FastAPI = application    |    Uvicorn = server
uvicorn app.main:app --reload  # Starts the FastAPI app in app/main.py and automatically reloads after code changes.
  • uvicorn: run the Uvicorn server.
  • app.main: go to the app package and load main.py.
  • :app: find the variable named app.
  • --reload: restart automatically whenever source code changes.
app = FastAPI()  # Creates the FastAPI object that Uvicorn will run.

Local server: http://127.0.0.1:8000. Swagger: http://127.0.0.1:8000/docs.

07

SQLAlchemy

SQLAlchemy lets Python communicate with a relational database. It is an ORM, meaning Object Relational Mapper.

Python class → database table
account = Account()  # Creates a Python object representing a new row in the accounts table.
db.add(account)       # Tells SQLAlchemy that this object should be added to the database.
db.commit()           # Saves the pending database changes permanently.
class Account(Base):                              # Defines a Python class mapped to a database table.
    __tablename__ = "accounts"                    # Names the actual database table "accounts".
    id = Column(Integer, primary_key=True)        # Creates an integer ID primary-key column.
    account_number = Column(String, unique=True)  # Creates a text account-number column and prevents duplicates.
    balance = Column(Numeric(15, 2), default=0)   # Creates a decimal money column with two decimal places.
08

SQLite

SQLite is a small relational database stored as a file. It is ideal for learning, prototypes, small applications, interview demos and local development.

DATABASE_URL = "sqlite:///bank.db"  # Tells SQLAlchemy that the database is a local SQLite file named bank.db.
engine = create_engine(             # Creates SQLAlchemy's connection engine for SQLite.
    DATABASE_URL,                   # Uses the database URL defined above.
    connect_args={"check_same_thread": False}  # Allows FastAPI requests to use SQLite safely across threads in this demo.
)
FastAPI → SQLAlchemy → SQLite → bank.db

SQLAlchemy is the Python database library. SQLite is the actual database. A production banking workload would normally use PostgreSQL or another managed database.

09

Pydantic

Pydantic validates data entering your API. For example, a banking transaction should not accept a zero or negative transfer amount.

from decimal import Decimal             # Imports Decimal, which is safer than floating-point numbers for money.
from pydantic import BaseModel, Field    # Imports Pydantic's model base class and validation helper.

class TransferRequest(BaseModel):        # Defines the expected structure of a transfer request.
    source_account: str                  # Requires the source account to be supplied as text.
    destination_account: str             # Requires the destination account to be supplied as text.
    amount: Decimal = Field(gt=0)        # Requires the transfer amount to be greater than zero.
    reference: str                       # Requires a transaction reference.
Client request → Pydantic validation → FastAPI endpoint → business logic
10

PyJWT

JWT means JSON Web Token. PyJWT creates and validates JWTs used for API authentication.

Login → verify credentials → create JWT → client stores token → token sent with future requests
import jwt  # Imports the PyJWT package.
token = jwt.encode(                       # Creates a signed JSON Web Token.
    {"sub": "123"},                      # Stores user ID 123 inside the token subject claim.
    "secret-key",                         # Uses a secret key to sign the token.
    algorithm="HS256"                    # Uses the HS256 signing algorithm.
)
Authorization: Bearer eyJhbGciOi...  # Sends the JWT in the Authorization header for protected API requests.
11

Pytest

Pytest is an automated testing framework for Python. It lets you verify the application automatically instead of manually retesting every endpoint after every code change.

from fastapi.testclient import TestClient  # Imports FastAPI's testing client.
from app.main import app                    # Imports the FastAPI application that will be tested.
client = TestClient(app)                    # Creates a test client connected to the FastAPI application.

def test_health():                          # Defines a test function discovered automatically by Pytest.
    response = client.get("/health")         # Sends a simulated GET request to /health.
    assert response.status_code == 200       # Fails unless the server returned HTTP 200.
    assert response.json()["status"] == "ok" # Fails unless the JSON response contains status="ok".
pytest     # Searches the project for tests and executes them.
pytest -q  # Runs all tests with shorter, cleaner output.
12

HTTPX

HTTPX is a Python HTTP client. It allows Python programs to make HTTP requests to web APIs and supports FastAPI testing workflows.

Python program → HTTPX → API
import httpx                                      # Imports the HTTPX library.
response = httpx.get("https://example.com/api")   # Sends an HTTP GET request to an API.
print(response.status_code)                       # Prints the HTTP response status, for example 200.
print(response.json())                            # Converts the JSON response into Python data and prints it.

.github/workflows/tests.yml

This file creates the GitHub Actions Continuous Integration pipeline. The .github/workflows/ directory is where GitHub automation workflows live.

name: CI                              # Gives this GitHub Actions workflow the visible name "CI".
on:                                   # Defines the events that should start this workflow.
  push:                               # Runs the workflow whenever code is pushed.
    branches: [main]                  # Limits push-triggered runs to the main branch.
  pull_request:                       # Also runs whenever a pull request is created or updated.
    branches: [main]                  # Only runs for pull requests targeting main.

jobs:                                 # Begins the section containing automated jobs.
  test:                               # Creates one job named "test".
    runs-on: ubuntu-latest            # Creates a temporary Ubuntu Linux machine.
    steps:                            # Begins the ordered list of actions.
      - uses: actions/checkout@v4     # Downloads your repository code onto the temporary machine.
      - uses: actions/setup-python@v5 # Installs and configures Python.
        with:                         # Begins setup-python configuration.
          python-version: "3.12"      # Specifies Python 3.12.
      - run: pip install -r requirements.txt  # Installs project dependencies.
      - run: pytest -q                # Runs the automated Pytest suite.
git push → checkout code → install Python → install dependencies → run tests → success or failure

This is Continuous Integration, or CI.

17

Dockerfile

A Dockerfile describes how to package your application into a portable container.

FROM python:3.12-slim  # Starts with a lightweight Linux image that already contains Python 3.12.
WORKDIR /app           # Creates and switches into the /app directory inside the container.
COPY requirements.txt .  # Copies the Python dependency file into the container.
RUN pip install --no-cache-dir -r requirements.txt  # Installs all project dependencies inside the container.
COPY . .               # Copies the rest of the project source code into the container.
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]  # Starts FastAPI when the container launches.
Source code + Python + libraries + runtime configuration = Docker image
18

render.yaml

render.yaml tells Render how to host the application. Storing deployment settings with the code is called Infrastructure as Code.

services:                                                     # Begins the list of services Render should create.
  - type: web                                                 # Tells Render this service should be reachable through the web.
    name: samuel-kimani-bank-api-demo                         # Gives the hosted service its Render name.
    runtime: python                                           # Tells Render that the application uses Python.
    plan: free                                                # Requests Render's free service plan.
    region: frankfurt                                         # Places the service in Render's Frankfurt region.
    buildCommand: python -m pip install --upgrade pip && python -m pip install -r requirements.txt  # Installs dependencies during deployment.
    startCommand: python -m uvicorn app.main:app --host 0.0.0.0 --port $PORT  # Starts FastAPI on Render's assigned port.
    healthCheckPath: /health                                  # Tells Render to call /health to verify the service started.
    autoDeployTrigger: commit                                 # Deploys when a new commit reaches the connected branch.
    envVars:                                                  # Begins deployment environment-variable configuration.
      - key: PYTHON_VERSION                                   # Defines the requested Python version.
        value: "3.12.14"                                      # Pins the service to Python 3.12.14.
      - key: JWT_SECRET                                       # Defines the secret used to sign authentication tokens.
        generateValue: true                                   # Tells Render to securely generate the secret.
      - key: DATABASE_URL                                     # Defines the SQLAlchemy database connection string.
        value: sqlite:///bank.db                              # Uses the local SQLite bank.db file for the demo.
      - key: ACCESS_TOKEN_MINUTES                             # Defines how long access tokens remain valid.
        value: "60"                                           # Sets access-token lifetime to 60 minutes.
GitHub → render.yaml → Render build → install requirements → start Uvicorn → check /health → public website
